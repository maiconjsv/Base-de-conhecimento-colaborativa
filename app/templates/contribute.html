Passo a passo para contribuir com uma feature

  1. Abra uma issue descrevendo a ideia

    Em Issues › New issue, explique qual problema a feature resolve, como deveria funcionar e, se possível, um exemplo. Para mudanças grandes, espere um retorno de @{{ github_user }} antes de começar, para alinhar a abordagem.

  2. Faça um fork e clone

    No GitHub, clique em Fork no repositório. Depois, na sua máquina:

    git clone https://github.com/SEU-USUARIO/Base-de-conhecimento-colaborativa.git
cd Base-de-conhecimento-colaborativa
git remote add upstream {{ github_repo }}.git

  3. Prepare o ambiente (Windows, Python 3.12)

    python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py

    Abra http://127.0.0.1:5000. No primeiro acesso o sistema pede para criar o usuário administrador. Os dados de desenvolvimento ficam em instance\ e uploads\, separados da sua instalação real.

  4. Crie uma branch para a feature

    git checkout -b feature/nome-curto-da-feature

  5. Implemente seguindo o padrão do projeto

    Onde fica cada coisa: rotas em app/documents/, busca em app/search.py, assistente em app/ask.py, planilhas em app/sheets.py, extração de texto em app/extract.py, telas em app/templates/ e visual em app/static/style.css. O README.md descreve a arquitetura.

    Regras importantes:

    • Tudo roda localmente, dentro do executável: nada de serviços externos ou envio de dados para fora.
    • Textos da interface em português.
    • Dependência nova vai no requirements.txt, com versão fixa, e precisa funcionar no build.
    • Mudou o banco de dados? Lembre que quem já usa o programa tem dados: só tabelas novas são criadas automaticamente.

  6. Teste

    Envie alguns arquivos (PDF, Word, Excel), faça buscas, use o Perguntar e abra os documentos. Se mexeu em dependências ou no empacotamento, gere o programa e abra o executável:

    .\build.ps1
.\dist\BaseConhecimento\BaseConhecimento.exe

  7. Faça commit e envie

    git fetch upstream
git rebase upstream/main
git add -A
git commit -m "Adiciona <descrição curta da feature>"
git push -u origin feature/nome-curto-da-feature

  8. Abra o Pull Request

    No seu fork, clique em Compare & pull request, com destino à branch main de {{ github_user }}/Base-de-conhecimento-colaborativa. Descreva o que muda, como testar e inclua prints de tela. Escreva Closes #N para ligar à issue. A revisão é feita por @{{ github_user }}.

Dúvidas sobre como contribuir? Escreva para {{ support_email }}.
