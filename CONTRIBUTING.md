# Como contribuir

O guia completo está no README: **[Como contribuir](README.md#como-contribuir)**.
Lá estão o passo a passo, o ambiente de desenvolvimento, as receitas para as mudanças
mais comuns, o checklist de testes e o modelo de Pull Request.

Resumo:

- **Suporte** (erro, dúvida de uso): maicon.vieira@atos.ai
- **Bug ou ideia**: abra uma [issue](https://github.com/maiconjsv/Base-de-conhecimento-colaborativa/issues/new)
  usando os modelos do README ([bug](README.md#reportando-um-bug) ·
  [feature](README.md#sugerindo-uma-feature)).
- **Código**: fork → branch `feature/…` a partir da `main` → teste com o
  [checklist](README.md#testando-sua-mudança) → Pull Request para a `main`,
  com revisão de [@maiconjsv](https://github.com/maiconjsv).
